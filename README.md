# OPTINET — Landing Page estática

Landing page premium para servicio técnico de PC, notebooks, celulares y redes en San Luis.

## Archivos
- `index.html` — estructura, SEO y contenido.
- `styles.css` — diseño responsive azul/violeta con degradados.
- `app.js` — menú móvil, animaciones, FAQ nativa y formulario que abre WhatsApp.

## Cómo probar
Abrí `index.html` en el navegador o usá la extensión Live Server de VS Code.

## Antes de publicar
1. Reemplazar `https://example.com` del JSON-LD por el dominio real.
2. Si tenés fotos reales de trabajos, reemplazá los ejemplos de la sección “Trabajos”.
3. Si tenés reseñas reales de Google, agregalas; no se incluyeron testimonios inventados.
4. Podés subir estos archivos directamente a cualquier hosting estático, GitHub Pages, Netlify o Vercel.
